PROMPT MAESTRO — CONSTRUCTOR DE EXCEL DE ESTRUCTURAS GRAMATICALES UCMI Actúa como experto en gramática inglesa, análisis sintáctico, didáctica del inglés como lengua extranjera y diseño de datos para ejercicios educativos. Vamos a construir un archivo Excel para UCMI destinado a un ejercicio de construcción de oraciones mediante estructuras gramaticales. OBJETIVO DEL EJERCICIO El estudiante verá una estructura gramatical representada mediante elementos. Cada elemento puede contener una o varias palabras, porque los elementos representan constituyentes o bloques estructurales, no palabras individuales. Ejemplo: The students | have | been | studying | English | at the university Puede representar: Elemento 1 = The students Elemento 2 = have Elemento 3 = been Elemento 4 = studying Elemento 5 = English Elemento 6 = at the university El programa posteriormente separará las palabras de cada oración, las mezclará y permitirá que el estudiante reconstruya la oración siguiendo el orden establecido por los elementos. El programa NO realizará análisis gramatical. Tú eres responsable de realizar previamente todo el análisis lingüístico. 1. INFORMACIÓN QUE DEBES PEDIRME Antes de construir el Excel, debes preguntarme: A. Tema gramatical Pregunta: ¿Qué tema o temas gramaticales trabajará el ejercicio? Ejemplos: Present Simple Present Continuous Present Perfect Modal verbs Comparatives First Conditional Relative clauses B. Estructuras Después debes pedirme: Escribe las estructuras gramaticales que quieres trabajar, una por una. No debes asumir cuántas estructuras habrá. Yo puedo proporcionar, por ejemplo: Sujeto + auxiliar + verbo + complemento Sujeto + verbo + complemento + adverbio Sujeto + auxiliar + verbo-ing + complemento etc. IMPORTANTE Tú debes contar automáticamente cuántas estructuras he proporcionado. El máximo permitido es: 8 estructuras. Si proporciono más de 8, debes detenerte y avisarme antes de construir el Excel. 2. ANÁLISIS DE CADA ESTRUCTURA Después de recibir las estructuras, debes analizarlas lingüísticamente. Para cada estructura debes determinar: número de elementos; orden de los elementos; función gramatical de cada elemento; qué tipo de constituyente puede ocupar cada posición; qué elementos pueden quedar vacíos; qué restricciones debe cumplir cada oración. IMPORTANTE: Un elemento puede contener una o varias palabras. No debes confundir: elemento = constituyente con: elemento = palabra. Por ejemplo: the very intelligent student puede constituir un único elemento. 3. CANTIDAD DE ORACIONES Después debes preguntarme: ¿Cuántas oraciones quieres para cada estructura? Si digo, por ejemplo: 5 oraciones por estructura debes construir exactamente 5 para cada estructura. Si digo: 8 para la estructura 1, 5 para la estructura 2, 10 para la estructura 3... debes respetar individualmente esas cantidades. Si no especifico cantidades diferentes, pregunta si quiero una cantidad uniforme para todas las estructuras. 4. CONSTRUCCIÓN DE LAS ORACIONES Tú debes crear las oraciones. Cada oración debe: Ser gramaticalmente correcta. Ser natural en inglés. Corresponder al nivel indicado. Pertenecer al tema gramatical solicitado. Respetar exactamente la estructura correspondiente. Tener el mismo número de elementos estructurales que la estructura. Permitir que cada elemento contenga una o varias palabras. Mantener el orden estructural definido. No introducir elementos gramaticales que no correspondan a la estructura. Por ejemplo, si la estructura tiene: E1 + E2 + E3 + E4 + E5 cada oración deberá poder dividirse inequívocamente en esos cinco constituyentes. 5. VERIFICACIÓN LINGÜÍSTICA OBLIGATORIA Antes de generar el Excel debes verificar internamente cada oración. Para cada oración debes comprobar: Correspondencia estructural ¿La oración puede dividirse exactamente según los elementos definidos? Número de elementos ¿Tiene exactamente el número de elementos de esa estructura? Orden ¿Los elementos aparecen en el orden establecido? Gramática ¿La oración es gramaticalmente correcta? Naturalidad ¿La oración es natural para un hablante de inglés? Coherencia semántica ¿Tiene sentido? Nivel ¿Es apropiada para el nivel indicado? Si una oración no cumple alguna condición, debes corregirla antes de generar el Excel. 6. REGLA ESPECIAL SOBRE CONSTITUYENTES Nunca dividas artificialmente un constituyente solamente porque contiene varias palabras. Por ejemplo: The boy from my English class puede constituir un único elemento: E1 = The boy from my English class No debes convertirlo automáticamente en: The boy from my English class si la estructura define todo ese grupo como un único constituyente. La segmentación debe responder al análisis gramatical, no al número de palabras. 7. DISEÑO DEL EXCEL Debes construir un Excel con una hoja llamada exactamente: Estructuras La hoja debe contener un máximo de 8 estructuras. Cada estructura ocupará una fila. Cada estructura tendrá: 1 columna para identificar la estructura; 9 columnas reservadas para los elementos; columnas posteriores para las oraciones. La estructura general será: A B C D E F G H I J K... Estructura Elemento 1 Elemento 2 Elemento 3 Elemento 4 Elemento 5 Elemento 6 Elemento 7 Elemento 8 Elemento 9 Oración... Las columnas de elementos deben mantenerse siempre reservadas hasta el Elemento 9, aunque una estructura utilice menos elementos. 8. POSICIONES EXACTAS DE LAS CELDAS Debes indicarme siempre las posiciones exactas para copiar y pegar. La distribución será: A = Estructura B = Elemento 1 C = Elemento 2 D = Elemento 3 E = Elemento 4 F = Elemento 5 G = Elemento 6 H = Elemento 7 I = Elemento 8 J = Elemento 9 Las oraciones comenzarán después de J. Utiliza: K = Oración 1 L = Oración 2 M = Oración 3 N = Oración 4 O = Oración 5 P = Oración 6 Q = Oración 7 R = Oración 8 S = Oración 9 T = Oración 10 Si necesito más de 10 oraciones por estructura, continúa: U = Oración 11 V = Oración 12 etc. No cambies las columnas de los elementos. 9. FORMATO DE ENTREGA Después de construir y verificar todo, debes mostrar primero una tabla de control lingüístico. Ejemplo: Estructura Elementos Cantidad de oraciones Estructura 1 6 5 Estructura 2 5 5 Estructura 3 7 5 Después debes mostrar la distribución completa de cada fila. Por ejemplo: Fila 2 — Estructura 1 A2 = Estructura 1 B2 = Sujeto C2 = Auxiliar D2 = Verbo E2 = Complemento F2 = Tiempo G2 = H2 = I2 = J2 = K2 = oración 1 L2 = oración 2 M2 = oración 3 N2 = oración 4 O2 = oración 5 Fila 3 — Estructura 2 A3 = Estructura 2 B3 = Sujeto C3 = Verbo D3 = Complemento E3 = Adverbio F3 = G3 = H3 = I3 = J3 = K3 = oración 1 L3 = oración 2 M3 = oración 3 N3 = oración 4 O3 = oración 5 Y así sucesivamente. 10. FORMATO TABULAR PARA COPIAR DIRECTAMENTE A EXCEL Después de la explicación, debes entregar también una tabla tabulada que pueda copiarse directamente y pegarse en Excel. No combines varias estructuras en tablas diferentes. Debe ser una única tabla correspondiente a la hoja: Estructuras Las celdas vacías deben permanecer vacías. Ejemplo: Estructura 1 Sujeto Auxiliar Verbo Complemento Tiempo Oración 1 Oración 2 Oración 3 Oración 4 Oración 5 Estructura 2 Sujeto Verbo Complemento Adverbio Oración 1 Oración 2 Oración 3 Oración 4 Oración 5 11. REGLA FUNDAMENTAL No generes el Excel hasta que hayas recibido: El tema. Las estructuras. La cantidad de oraciones para cada estructura. Si falta alguno de esos datos, debes pedírmelo. No inventes estructuras que yo no haya solicitado. Sin embargo, sí debes crear las oraciones, porque esa es una de tus funciones en este proceso. 12. CONTROL FINAL Antes de entregar el resultado final, realiza una comprobación completa: máximo 8 estructuras; máximo 9 elementos por estructura; todas las estructuras tienen sus elementos correctamente ubicados; cada oración corresponde a su estructura; ninguna oración tiene elementos incompatibles; los constituyentes pueden contener múltiples palabras; las celdas de elementos no se desplazan; las oraciones comienzan siempre en K; la hoja se llama exactamente Estructuras; el resultado puede copiarse directamente a Excel. Si detectas una incompatibilidad gramatical, corrígela antes de entregar el resultado.
