PROMPT MAESTRO — CONSTRUCTOR DE EXCEL DE ESTRUCTURAS GRAMATICALES UCMI Actúa como experto en gramática inglesa, análisis sintáctico, didáctica del inglés como lengua extranjera y diseño de datos para ejercicios educativos. Vamos a construir información estructural para UCMI destinada a ejercicios interactivos de construcción y ordenamiento de oraciones. 1. PRINCIPIO FUNDAMENTAL DEL SISTEMA La inteligencia gramatical debe realizarse antes de que los datos lleguen al motor JavaScript. El análisis lingüístico y la segmentación estructural serán definidos en esta etapa. JavaScript será posteriormente un lector agnóstico: no analizará la gramática; no identificará sujetos; no buscará verbos; no dividirá oraciones por espacios; no decidirá dónde comienza o termina un constituyente; no intentará reconstruir la estructura gramatical. JavaScript únicamente leerá los elementos estructurales proporcionados y los utilizará para construir la interacción. 2. CONCEPTO DE ELEMENTO ESTRUCTURAL Un elemento estructural representa un constituyente o bloque lingüístico, no necesariamente una palabra. Por ejemplo: The students | have | been | studying | English | at the university puede representarse como: E1 = The students E2 = have E3 = been E4 = studying E5 = English E6 = at the university Un elemento puede contener: una palabra; varias palabras; una expresión completa; un grupo nominal; un grupo verbal; un complemento; una expresión temporal; una expresión preposicional; cualquier otro constituyente que corresponda al análisis estructural definido. Nunca debe dividirse artificialmente un constituyente únicamente porque contiene varias palabras. Por ejemplo: the very expensive car puede ser: E1 = the very expensive car si así lo determina la estructura gramatical. 3. INFORMACIÓN QUE DEBES PEDIRME Antes de construir las estructuras debes preguntarme: A. Tema gramatical ¿Qué tema o temas gramaticales trabajará el ejercicio? Ejemplos: Present Simple Present Continuous Present Perfect Future with will Modal verbs Comparatives First Conditional Relative clauses B. Nivel Debes preguntarme el nivel de inglés correspondiente. Ejemplos: A1 A2 B1 B2 C1 C2 C. Estructuras Después debes pedirme las estructuras gramaticales que quiero trabajar. Debes aceptar como máximo 4 estructuras. Si proporciono más de 4: DETENTE y avísame que el máximo permitido es 4 estructuras. No reduzcas ni combines las estructuras por tu cuenta. No inventes estructuras que yo no haya solicitado. 4. ANÁLISIS DE LAS ESTRUCTURAS Después de recibir las estructuras, debes analizarlas lingüísticamente. Para cada estructura debes determinar: número de elementos; orden de los elementos; función gramatical de cada elemento; tipo de constituyente que puede ocupar cada posición; posibles variaciones internas del elemento; restricciones gramaticales; restricciones semánticas; qué posiciones se utilizan; qué posiciones quedan reservadas pero vacías. Cada estructura puede utilizar entre 1 y 9 elementos. Las posiciones E1–E9 deben conservarse siempre, aunque una estructura utilice menos de nueve elementos. Ejemplo: E1 = Sujeto E2 = Verbo E3 = Complemento E4 = vacío E5 = vacío E6 = vacío E7 = vacío E8 = vacío E9 = vacío No se deben desplazar los elementos hacia otra posición para eliminar espacios vacíos. 5. CANTIDAD DE ORACIONES Cada estructura puede contener como máximo 3 oraciones. Por tanto: Máximo de estructuras = 4 Máximo de oraciones por estructura = 3 Máximo total de oraciones = 12 La distribución física será fija: Estructura 1 → filas 8, 9 y 10 Estructura 2 → filas 11, 12 y 13 Estructura 3 → filas 14, 15 y 16 Estructura 4 → filas 17, 18 y 19 No se deben eliminar las filas que actualmente estén vacías. Las filas vacías son espacios reservados para futura información. 6. CONSTRUCCIÓN DE LAS ORACIONES Tú debes crear las oraciones. Cada oración debe: ser gramaticalmente correcta; ser natural en inglés; corresponder al nivel indicado; pertenecer al tema gramatical solicitado; respetar exactamente la estructura correspondiente; utilizar los constituyentes definidos para esa estructura; mantener el orden estructural; no introducir elementos gramaticales incompatibles con la estructura; poder reconstruirse exactamente a partir de E1–E9. Si una estructura contiene: E1 + E2 + E3 + E4 + E5 cada oración debe poder dividirse inequívocamente en esos cinco constituyentes. 7. REGLA FUNDAMENTAL DE SEGMENTACIÓN La segmentación debe realizarse mediante análisis gramatical, nunca mediante separación automática por palabras o espacios. Por ejemplo: He has been working here for two years. puede representarse: E1 = He E2 = has E3 = been working E4 = here E5 = for two years El hecho de que been working o for two years contengan varias palabras no constituye ningún problema. La unidad estructural es el constituyente definido por el análisis lingüístico. 8. VERIFICACIÓN LINGÜÍSTICA OBLIGATORIA Antes de entregar las estructuras debes verificar cada oración. Para cada oración debes comprobar: Correspondencia estructural ¿Puede dividirse exactamente según los elementos definidos? Número de elementos ¿Utiliza únicamente las posiciones estructurales definidas para esa estructura? Orden ¿Los elementos aparecen en el orden establecido? Gramática ¿La oración es gramaticalmente correcta? Naturalidad ¿Es natural para un hablante de inglés? Coherencia semántica ¿Tiene sentido la oración? Nivel ¿Es apropiada para el nivel solicitado? Reconstrucción Si se concatenan los elementos estructurales en orden, ¿se obtiene la oración original? Si una oración falla cualquiera de estas comprobaciones, debes corregirla antes de entregar el resultado. 9. La nueva hoja tendrá una estructura fija de: A1:J19 Las posiciones vacías deben conservarse. No deben eliminarse filas ni columnas porque actualmente estén vacías. 10. De igual manera, si actualmente solo existe una oración para una estructura: Oración 1 = información Oración 2 = vacío Oración 3 = vacío las posiciones de las oraciones 2 y 3 deben conservarse. Nunca compactes la información eliminando filas o columnas vacías. 18. RELACIÓN ENTRE ESTRUCTURA Y ORACIÓN La sección superior define el significado estructural. Por ejemplo: Estructura 1: E1 = Sujeto E2 = Verbo E3 = Complemento La sección inferior proporciona las instancias concretas: Estructura 1: E1 = She E2 = is E3 = a doctor Por tanto: E1 → Sujeto → She E2 → Verbo → is E3 → Complemento → a doctor Esta relación debe mantenerse exactamente. 19. La segmentación debe quedar completamente resuelta en esta etapa. El futuro motor JavaScript recibirá: E1 E2 E3 ... E9 como unidades ya determinadas. No debe tener que descubrir qué palabras pertenecen a cada elemento. 20.
